# BALI Academy

Monorepo for the BALI Academy staff learning platform.

- `admin-desktop/` — Windows/desktop administration application.
- `ios-staff/` — native SwiftUI application for staff.
- `content/` — GitHub-backed knowledge base, tests and aliases.
- `.github/workflows/` — build and validation workflows.

> Content is stored in GitHub JSON files. The staff app reads content without embedded write credentials; the desktop admin app is the only writer.
